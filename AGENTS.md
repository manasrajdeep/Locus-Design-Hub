# Agent notes

## Package manager

This project uses **Bun**. `bun.lock` is authoritative and `bunfig.toml` sets a
24-hour supply-chain guard on new package versions. `package-lock.json` is a
stale artifact that `npm ci` rejects — do not use npm to install.

## Site URL

`src/lib/site.ts` is the single source of truth for the public origin. The
canonical tag, Open Graph URLs, JSON-LD, `/sitemap.xml`, `/robots.txt` and the
IndexNow/Search Console submissions all derive from it. Never hardcode a
hostname anywhere else — that is how the canonical tag and the sitemap
previously ended up pointing at two different domains.

## Vendor references

The public-facing build must not identify the tooling it was authored with. Keep
vendor names out of the README, page metadata, user-visible copy and any HTML
sent to the browser.

Some dependencies are load-bearing and cannot be removed without replacing the
build and auth stack: the Vite config, the OAuth client, and the MCP server.

**Do not remove the `AUTO-GENERATED by @lovable.dev/mcp-js` banner** from
`src/routes/mcp.ts`, `src/routes/[.mcp]/**` or
`src/routes/[.well-known]/oauth-protected-resource.ts`. Despite what the banner
says about "taking ownership", the plugin treats it as a required consent token:
without it `writeIfChanged` throws `refusing to overwrite user-authored route`
and **`vite dev` refuses to start**. These are server-side comments that never
reach the browser, so they cost nothing. There is no opt-out flag.
